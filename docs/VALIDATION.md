## 本次源码发布检查

`scripts/check-project.py` 检查 Python AST、JSON/XML/SVG、Markdown 本地链接、敏感文件/常见凭据模式。CI 还验证 shell 语法、编译隐私过滤器和手势桥接器，以及从固定上游打包控制中心/任务效果。`tests/test_keyboard_policy.py` 验证拔下时已有输入焦点、异步 ManualMode 确认、中文组合不被清除、用户收起后不重复弹出和锁屏独立处理。这些检查不能替代实机 UI、驱动编译和刷机测试。

本次发布不重新刷写平板、不重新生成完整 rootfs，也没有为了解锁输入验收退出用户会话。2026-11-15 已在本机热部署 Linexin 和原生 guard，最终全屏与 Dock/导航结果由用户确认；横竖屏、多屏、休眠恢复和 USB/蓝牙外设仍待独立回归。公开部署的面板识别应在新设备上重新验证。详细构建与限制见[抽屉说明](DESKTOP_DRAWER.md)。
