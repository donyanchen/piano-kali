# 桌面与交互说明

以下描述当前实机最终行为；基础镜像和增量组件的区别见 [部署手册](DEPLOYMENT.md)。参考澎湃控制中心和 Windows 触摸板选窗逻辑，以 Plasma/KWin 原生会话实现，未移植 Android SystemUI。

## 桌面布局

```text
┌────────────────────────────────────────────────────────┐
│ 启动器/窗口/全局菜单       HH:mm:ss        托盘/电池/网络 │ ← 40 逻辑像素
│                            MM-dd          ↓ 控制中心   │
├────────────────────────────────────────────────────────┤
│ 桌面时钟 / 天气             │                          │
│                            │ 无鼠标/触摸板时：         │
│ Miku 壁纸                   │ 桌面整个右半区下滑打开     │
│                            │ 控制中心                 │
│       任意空白区域上滑 → Linexin 全屏应用抽屉            │
│              ┌──── Linexin 应用 Dock ────┐              │ ← 84 逻辑像素
└────────────────────────────────────────────────────────┘
```

- 一个虚拟桌面；200% 显示缩放。默认 BreezeLight 配色、Breeze 窗口/控件、Colloid-Light 图标。
- 指针 `Breeze_Light`、24px，白色主体配深色描边。桌面与状态栏前景白色，电池采用白色符号遮罩。
- 顶栏时间独立固定在屏幕中心，不因终端菜单宽度改变位置。24 小时、常显秒；第二行日期 `MM-dd`，字号小于时间。
- 活动窗口最大化/全屏，Dock 向下滑出隐藏；还原小窗口/最小化，Dock 向上滑入显示。由原生 Plasma 面板动画执行。
- 隐藏后底边两次上滑依次显示白条和临时 Dock；点击外部窗口立即向下收起，原点击继续生效。临时 Dock 显示时，再从底边上滑一次返回桌面，应用保留在后台；回到应用后恢复自动隐藏。
- Dock 显示时采用窗口可在其下方铺开的覆盖模式。Linexin 抽屉真正全屏，复用原来的同一个 Dock；开关抽屉时 Dock 不随内容淡入/缩放。桌面触屏上滑、抽屉左右翻页/下滑收起及长按编辑见[抽屉说明](DESKTOP_DRAWER.md)。
- 桌面触屏拖动不触发框选；原生 KWin 插件只处理桌面表面，鼠标/触摸板框选与应用触屏保持原输入路径。
- 桌面使用 Miku 白裙图；锁屏使用暗色 Miku「深海少女」。壁纸来源见 [theme](../device/theme/README.md)，图片不随源码分发。
- Redmi Clock 天气使用网络近似定位，不使用 GPS；HTTPS、缓存与失败退避。断网保留上次有效结果，首次无数据显示 `—°`，不会把整行天气删除。

## 控制中心

从**状态栏右侧下滑并松手**打开，没有独立点击按钮。当未连接鼠标或触摸板时，还可从**桌面整个右半区**下滑打开。PIN 触摸板计作鼠标；实际拔下 PIN 后即使输入节点仍残留，也按物理连接状态判断。**应用窗口内没有整条最右侧下滑入口。**

右半区触摸开始时临时暂停桌面的长按编辑触发，避免慢速下滑误入编辑模式；普通点击继续传递，手势结束并经过原长按超时窗口后恢复原规则。手动进入桌面编辑模式时暂停该下滑入口。

原有 Wi-Fi、蓝牙、亮度托盘图标仅接受鼠标点击；触屏被拦截，统一使用下滑控制中心。控制中心可在浅色与深色模式间适配，大小为原设计 85%；Wi-Fi 与蓝牙大卡片、媒体卡片、竖向亮度与音量、热点等圆形开关。热点使用独立共享网络图标，夜间色温开关显示“护眼模式”。

| 起始位置/动作 | 结果 |
| --- | --- |
| 普通卡片/按钮区域上滑 | 收起控制中心 |
| 亮度或音量滑条上滑/拖动 | 实时调整数值，保持展开 |
| Wi-Fi 或蓝牙列表内上滑 | 只滚动列表，保持展开 |
| 点击面板外部 | 关闭 |
| 热点开关 | 控制 `sheng-hotspot.service`，与状态栏同步 |
| 隐私开关 | 一次阻止/恢复摄像头、麦克风、定位请求 |

UI 源码：[control-center](../device/control-center/README.md)。Wi-Fi、蓝牙状态由系统后端维护，加载 UI 不强制切换开关；关闭面板后不持续轮询。

## 三指触摸板与任务卡片

| 动作/状态 | 结果 |
| --- | --- |
| 独立三指上下滑 | 无动作，不打开任务卡片、不切换虚拟桌面 |
| 三指左右滑 | 进入原生 Alt+Tab 应用预览 |
| Alt+Tab 中保持三指，四向滑动 | 同向发送原生方向键选择目标：左选左、右选右，上下按网格行移动 |
| 到首尾 | 停住，不循环；有位移门限、反向滞回与节流 |
| 松开手指 | 确认当前窗口 |
| `Meta+W` | 保留独立澎湃风格任务卡片入口 |

原生 Alt+Tab 使用系统 `thumbnail_grid` 模型，未自行重造应用列表。任务卡片是另一 KWin QML 效果，提供实时 GPU 窗口缩略图、约 220ms 淡入淡出与模糊背景。两者不可混淆。[实现与打包](../device/recents/README.md)。

## 键盘、电源与内存

连接实体键盘时，触屏点文本框不会自动弹出软键盘；断开后恢复触屏输入。水杉使用 Fcitx5 引擎框架与 Fcitx5 OSK 屏幕键盘：PIN 和触屏中文均已用户确认。悬浮模式为 640/480 逻辑像素横/竖屏宽度，长按顶部拖动区约 1 秒后移动；工具栏“停靠/悬浮”切换位置。新的澎湃风格皮肤提供圆角键帽、蓝色回车键、简化工具栏，用户确认中文、拖动与模式切换正常。新输入法的锁屏/挂起恢复仍需独立验收，见 [input-method](../device/input-method/README.md)。

电源短按在插电/离电状态下均锁屏，长按正常关机。插电闲置 **60 分钟**同时锁屏、息屏，后台服务继续；离电闲置 **30 分钟**同时锁屏、息屏并 s2idle 挂起，后台网络暂停，恢复后重新同步热点和桌面输入状态。

6 GiB Zstd ZRAM 优先级 100，8 GiB 磁盘 swapfile 优先级 10；`swappiness=160`、`page-cluster=0`。交换仅在有压力时发生，不强制追求高使用率。ZRAM 的逻辑容量不等于额外物理 RAM。

## 隐私开关边界

开启隐私统一拒绝新摄像头、麦克风、定位请求：设备 cgroup BPF、D-Bus mandatory 策略及输入源/采集路由控制协作。已有直接采集句柄的进程会移入冻结 cgroup，关闭后恢复原进程；播放与必要的解码设备保留。

实测包括 root 新开采集设备/另建同类节点返回 EPERM，以及持有测试句柄的进程冻结/恢复。没有启用 BPF LSM，不能声称逐次 `read()` 系统调用全部被 LSM 拒绝，也不抵抗主动关闭保护的管理员。设备未检测到可用 GNSS，不能宣称实测 GPS 定位成功。详细范围及恢复命令见 [privacy](../device/privacy/README.md)。

## 复现注意

状态栏白色遮罩、Panel Colorizer、Redmi Clock、图标和壁纸是主题层依赖，需按新设备的 widget ID 配置。`layout.js` 是布局种子，不包含作者整份用户配置；控制中心安装后还要添加到顶部面板，DesktopPolicy 包还要添加桌面手势部件并启用 KWin 效果。请按 [部署手册](DEPLOYMENT.md) 完成各层后再验收。
